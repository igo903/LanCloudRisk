# LanCloudRisk · 岚云风控

A股市场与科技行业研究工作台。当前版本 **v0.7.0**，提供市场环境、自选股七维研究、情绪偏离、估值与基本面、多因子筛选，以及笑哭脸信号与交易回测。

## 本地运行

运行环境：Python 3.9 或以上。运行程序仅使用 Python 标准库，无须安装第三方 Python 包。

```bash
python3 run_risklens_local.py
```

浏览器自动打开 `http://127.0.0.1:8765/`。程序需要联网获取公开数据；按 `Ctrl+C` 停止服务。首次财务和公告抓取通常较慢，行情会先更新，研究证据随后补齐。Windows 可使用 `py run_risklens_local.py`。

可选参数：

```bash
python3 run_risklens_local.py --port 8766 --no-browser
python3 run_risklens_local.py --cache ./data/market-cache.json
python3 run_risklens_local.py --no-refresh
```

默认仅监听本机。缓存写入使用独立临时文件与原子替换；目录不可写时自动尝试用户应用数据目录和用户临时目录，全部失败时仍可在内存中使用最新行情。实际缓存状态可在“数据与方法”查看。

## 卡片与表现窗口（v0.7）

- 参考Polymarket公开卡片的紧凑布局，统一外围资产和六ETF卡片：标识与标题、突出数值、双列区间表现、底部日期/来源、可展开解读。保留本系统风险分口径与A股涨红跌绿，不把风险关注分显示为事件概率。
- 风险总览显示15类外围资产卡片，并可按宏观、海外股市、离岸中国、贵金属/加密筛选。SOX独立接入Yahoo Finance的`^SOX`日线；SOXX保留为ETF。二者各占外围风险6%，合计保持原半导体12%预算。
- “我的自选”新增60日和220日表现列；六ETF在风险总览与市场模块共用卡片，均显示60日涨跌。按有效日频间隔计算，分别需要61/221条日线。短历史保持缺失，盘中最后价格随刷新更新；不补造上市前数据。
- SOX身份参照Nasdaq官方介绍：https://indexes.nasdaq.com/Index/Overview/sox 。SOXX与SOX的编制基准和权重并不相同，不互相替代。

## 风险总览

- 外围风险：15类资产占80%，政治/地缘威胁10%，战争/冲突行动10%。每项保留解读、数据时间、来源及有效权重。
- A股指数风险：六ETF本地风险70% + 外围风险30%。自选风险：每只自身七维75% + A股风险25%；页面总览为八只自选等权观察，并非账户持仓风险。
- 分数0–100，越高越需关注。权重与阈值为透明研究假设，尚未实证校准，不是亏损或战争概率。缺失和过期项按有效权重逐层扣除，覆盖不足60%不显示点分，并展示缺失边界。
- 政治与战争分项使用Caldara / Iacoviello GPR的威胁、行动子项30日均值，在近3年中的历史分位。至少252个有效滚动样本；日频数据每周更新，超过14天停用。官方背景条目只作有日期的解释，不参与自动评分，不代表自动新闻监测。
- 自选自身七维：趋势20%、经营/ETF成分20%、估值10%、资金10%、波动15%、回撤15%、治理事件10%。缺估值同业/历史分位、ETF申赎、原文事件影响判断时保留缺失，不用公告数量代替风险影响。
- 外围与产业传导新增60、250个有效日频间隔变化（需61/251条观察）；美债收益率使用bp。黄金/白银是连续期货价格代理，含换月影响；其余均非分红再投资总回报。
- 全球日线来自Yahoo Finance；恒生科技历史用腾讯、USD/CNH与富时中国A50历史用东方财富补充，均核对标的代码。当前验证中19项外围标的可计算60/250日窗口。A50备用历史接口已核对代码，但本环境随后返回503，当前仅有最新点位，长窗口保持缺失。来源不可用时保留带日期的旧快照与可用历史，历史不足时不补造收益。
- 笑哭脸回测新增策略解释：三因子公式、资金缺失处理、六ETF≥4只低于MA10过滤、历史信号日口径、对买卖单的不同影响，并显示当前开关状态。

## 主要功能

- 行情刷新先重新获取历史日K、核验上一交易日收盘记录，再更新当天累计OHLC和成交量。盘中日K标为未确认。
- 笑哭脸回测使用可缩放、平移的HTML5 K线图，支持日期、仓位、成本与执行模型重算。绩效计算只使用已确认收盘K线。
- 订单表在实际卖出行展示本轮收益率、对应买入笔数、买入成本及卖出净额；表尾展示当前区间总收益率。未成交不参与结算。
- 研究证据包括公开财报、历史资金流、公司公告、ETF披露持仓与净值，展示来源、期间和数据缺口。
- 市场与行业提供六类ETF趋势、大小盘及科技相对强弱、半导体/通信代理与外围科技行情传导分析。

观察ETF：沪深300、中证A500、中证500、中证1000、创业板、科创50。

自选：光迅科技、长飞光纤、长鑫科技、中芯国际、同花顺、天华新能、515980、588080。标的身份与各字段以程序内来源及日期为准。

## 研究记录、资金与风格

- 研究记录支持逐条删除、清空全部和撤销最近一次删除。删除前会确认；撤销仅保留在当前页面内存中，刷新后失效。兼容原有记录，清空不会影响行情快照和风格偏好。
- 初始研究资金为 **¥1,000,000（100万元）**，实际订单数量、成本、净值及总收益均基于该金额计算。
- 顶栏“风格”可切换“明亮”和“Polymarket 深色”。深色为深蓝底、亮蓝操作色的设计风格，保留A股涨红跌绿；包含图表、表格和弹窗。选择保存在当前浏览器，刷新后恢复。此项目与Polymarket无关联。

## 收益计算口径

**本轮收益率** =（卖出净额 − 对应买入成本）÷ 对应买入成本。买入成本合并实际成交买入并计入设定费用；部分卖出按数量分摊加权成本。滑点体现在模拟成交价格中。当前执行模型建仓后不重复加仓，结算函数支持多笔买入合并。

**总收益率** = 期末资产 ÷ 初始资金 − 1。期末资产包含现金与剩余持仓按最近确认收盘价的估值，仅统计当前所选回测区间，与策略收益卡片一致。没有实际模拟成交时，订单汇总行显示“—”。

## 数据与模型限制

行情为刷新时获取的公开报价快照，并非逐笔推送；财务和持仓披露具有各自更新频率。数据源接口可能变更或不可用，一致预期、独立个股舆情、完整事件影响尚未接入。演示模式使用合成数据，页面有明确标识。

未复权行情及简化成交假设可能影响回测；尚未完整建模分红除权、排队、部分成交和全部税费规则。研究结果不等同实盘绩效。本版暂未建设账户/持仓风控，不连接券商或自动下单。
