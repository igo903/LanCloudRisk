# 个股七维分析：公司研究证据

更新日期：2026-11-23（北京时间）。

七维页保留原有行业、基本面、估值、资金、技术、情绪和事件入口，新增公司研究摘要，以及每个维度的公司证据与反证。当前研究使用公开行情、公司财报、公告和新闻，不读取券商持仓，不执行交易。

## 内容与来源

| 研究内容 | 数据或方法 | 输出与约束 |
| --- | --- | --- |
| 主营业务、主要产品、收入构成 | iFinD `get_stock_info` / `global_stock_profile` | 保留证券代码、报告期、披露日期及原文链接；概念不等于收入 |
| 增长、经营现金、资本开支、ROIC、研发资本化、股份支付 | iFinD `get_stock_financials` / `global_stock_financial` | 每次最多五个指标；只接受可核验结构化字段，金额和百分比保留原单位，不覆盖既有财务数据 |
| 主力分类资金、超大单与大单 | 平安证券 market-query `capitalFlow` | 仅用于 A 股股票；金额为元，未返回观察时间时明确显示缺失，不计入当日或连续净流入 |
| 资金分布与经纪商、流向、卖空异动 | 富途 unusual capital-flows | 近七个自然日，保留供应商各类结论；“没有异动”和“没有取得数据”分开显示 |
| 公司新闻与事件摘要 | 富途 news search + stock digest 工作流程 | 近30日公司关联新闻、去重、发布时间和原文；摘要由保守规则归纳，拟议/否认/传闻保持待核实，正负线索并存保持中性 |
| 公告与产品兑现 | iFinD `search_notice` + 既有公告 | 检索片段保留链接，不冒充公告全文；核对计划、执行与实际兑现的区别 |
| 科技炒作与基本面 | tech-hype-fundamentals 分析框架 | 增长与估值、现金转换、研发与股份支付、资本效率、商业化、治理六项验证；不照搬固定行业溢价、目标价或实现概率 |

框架规则不是估值定价模型。页面将“PE（TTM）>60 且收入增长<20%”标为需核对的研究阈值；累计报告同比不用于前瞻 PEG。GAAP 净利润已包含股份支付时，不再重复扣减。ROE 不替代 ROIC。非科技公司使用经营与估值框架；ETF 仍使用成分穿透、净值与申赎研究。

## 如何更新

1. 本地运行新版 `run_risklens_local.py`，打开股票七维页。
2. 点击“补充 / 刷新公司研究”，强制重读该股研究证据。此操作不重新获取价格；已有行情源短时失败不阻断研究补充。
3. 展开“来源连接、缺口与证据日期”，查看各来源的成功、部分返回、跳过、失败及旧证据保留状态。

全量行情刷新和单股刷新也会补充研究；独立研究采用六小时缓存，按钮可绕过缓存。请求使用已有行情密钥专区配置，不添加新的服务密钥，不将密钥或私钥写入仓库。

研究刷新要求已有一份有效的公司行情快照。单独刷新只更新 `research_evidence` 和快照版本，保留价格时间、原财报口径与历史 K 线；并发的价格刷新不能擦除较新的研究。来源失败时分别保留该源旧证据及原读取日期。新闻及最新经营信息不会回填到历史回测或改写成交信号。

## 富途资金异动授权

资金异动通过官方富途 CLI 调用：

```sh
futu auth login
futu unusual capital-flows SZ.002281 --time-range 7 --language-id 0 --format json
```

这需要在运行服务的电脑安装支持 `unusual` 的新版 [Futu CLI](https://github.com/FutunnOpen/futu-cli)，并完成独立 OAuth 授权。网页行情 AppKey 的连通性测试通过，不代表 CLI 已登录或具有资金异动权限。程序会检查 PATH、Mac/Linux 的 `~/.futu/bin/futu` 以及 Windows 的 `%LOCALAPPDATA%/FutuCLI/bin/futu.exe`；不会替用户发起登录或打印 CLI 凭据。

缺少 CLI、未登录、权限不足或版本不支持，会明确记录跳过原因，不使用 OpenD、Python SDK 或其他账户数据冒充该结果。
