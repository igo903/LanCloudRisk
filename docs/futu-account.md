# 富途账户入口

更新日期：2026-11-23（北京时间）。

左侧“账户”页按需读取富途授权账户的可用资金、当前持仓和今日未成交订单。多账户时先选择账户，单账户可直接读取。该页独立于行情与七维研究，不使用演示账户数据。

## 首次连接

1. 在运行 `run_risklens_local.py` 的电脑安装[官方 Futu CLI](https://github.com/FutunnOpen/futu-cli)。Mac/Linux 默认路径为 `~/.futu/bin/futu`，Windows 为 `%LOCALAPPDATA%/FutuCLI/bin/futu.exe`，也支持 PATH 中的 CLI。
2. 在该电脑终端执行 `futu auth login`，按富途页面提示完成账户授权。程序先检查 CLI 版本及登录状态，再读取业务数据。
3. 打开左侧“账户”，点击“连接 / 重新读取账户”，选择账户及资金展示币种。
4. 点击“刷新账户数据”更新。字段读取失败会分别显示错误；同一账户、同一展示币种的旧数据可保留，并明确标注原读取时间。切换账户或币种会清空旧显示，迟到响应不会覆盖新账户。

行情密钥专区的富途 AppKey 不等于 CLI 的账户 OAuth 授权。若富途返回 `PERMISSION_DENIED`，表示服务端拒绝该账户读取，不将其解释为“没有 token”。程序不会自动打开授权、修改默认账户或替用户扩展权限。

## 展示口径

| 区域 | 字段与口径 |
| --- | --- |
| 可用资金 | `available_funds`，不以现金余额或融资购买力代替 |
| 现金、冻结现金、购买力、可提取金额、总资产 | 分别展示 `cash`、`frozen_cash`、`power`、`max_withdrawal`、`total_assets`；采用富途返回的展示币种 |
| 当前持仓 | 证券、方向、原币种、数量、可卖数量、有效成本价、参考价、市值、持仓盈亏、盈亏率、当日盈亏；跨币种不直接合计 |
| 今日未成交订单 | 各市场交易所当地日期的今日新建、等待提交/提交中/已提交未成交/部分成交及撤单处理中订单；已全部成交、已撤、失败等终结状态排除 |
| 未成交数量 | 委托数量减已成交数量，必须两字段均取得；缺少数量时不擅自补零 |

订单创建时间可为秒、毫秒、微秒或纳秒 Unix 时间。无时区的日期字符串不会被猜测时区。美股以纽约日期、港股以香港日期、沪深股通以上海日期筛选；页面同时标注各市场日期，并将订单时间转换为北京时间展示。此前创建的 GTC 订单不在“今日新建”列表。

订单查询按账户 `enable_market` 所列的已授权市场分别读取，使用显式 `--account`、`--market`；CLI 自动分页。尚未接入的市场编号、未返回市场信息、读取失败及无法分类的订单会明确显示，不能据此宣称“没有未成交订单”。

官方 CLI 会省略数值为零的部分 JSON 字段。缺少价格、成交数量或有效性标记时保留为 —；不把缺失当成零。持仓成本/盈亏以供应商有效性标记为准。页面“读取时间”不冒充证券实际最新成交时间。

## 数据处理

- 后端仅允许官方 CLI 的 `version`、`auth status`、`account list`、`account funds`、`position`、`order list`，参数由程序校验并以参数数组传递。
- 新增本地 `POST /api/account/read`，要求页面同源校验和有效页面会话；不提供公开 GET 账户端点。
- 不提供下单、修改订单、撤单或资金划转操作。
- 账户响应设置 `Cache-Control: no-store`，不进入 `DataStore.snapshot`、行情缓存、研究快照导出或浏览器持久存储。页面数据仅存在于当前页面内存，账户标识默认掩码显示。
- “清除本页数据”会清空内存并作废在途响应，不清除富途 CLI 授权。
- 默认服务仅监听本机。若自行部署到局域网或公网，需在访问层配置账户访问认证；页面会话校验不等于用户登录认证。

当前开发环境没有可用的富途 CLI 账户授权，真实账户连接需在用户部署电脑完成。接口、日期筛选和页面状态使用非个人数据的测试样例验证。

## Mac 安装失败的修复与诊断

若出现 `curl: (16) Error in the HTTP2 framing layer`，说明下载链路的 HTTP/2 传输失败；随后 `~/.futu/bin/futu` 不存在是安装未完成的结果。具体是代理、中间网络还是 curl 与服务器兼容性导致，仅凭该错误不能区分。

推荐在账户页下载“Futu 安装与诊断工具”，在运行服务的 Mac 终端执行：

```sh
python3 "$HOME/Downloads/install_futu_cli.py" --login
```

从仓库运行时，可执行：

```sh
python3 tools/install_futu_cli.py --login
```

该工具不调用 curl 或导出 Shell 函数，使用 Python 标准库 HTTPS（HTTP/1.1）查询官方版本、下载当前 CPU 架构对应的发行包、校验文件及签名。保留 HTTPS 证书验证、官方签名和 SHA-256 校验，不需要 sudo，不修改 shell 配置。验证完成后再原子替换程序，安装失败保留旧程序。

程序安装到 `~/.futu/bin/futu`。已正常安装时跳过下载，直接检查 CLI 登录；`--login` 在需要时进入官方登录流程，由用户在浏览器完成授权。工具不读取账户持仓，不输出令牌。下载、签名、写入、版本或登录检查失败时会显示具体阶段，安装失败时不会继续登录。

如当前程序损坏或需要重新安装，可增加 `--force`。若下载失败，先反馈最后一行 `[失败阶段：…]`；目录权限不足与 OAuth 未登录会分别报告，不再笼统判断为“没有权限”。

Python 自身证书配置异常时需要先修复其证书配置；工具不会关闭 TLS 校验。安装成功不等于 OAuth 授权完成，账户仍需通过富途授权后才能读取。
